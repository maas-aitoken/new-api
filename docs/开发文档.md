### TokenRequestRateLimit
基于多级令牌桶实现的请求速率限制，支持平台级和令牌级配置。

实现见 [`middleware/token_rate_limit.go`](../middleware/token_rate_limit.go)、
[`common/limiter/token_bucket.go`](../common/limiter/token_bucket.go)、
[`common/limiter/lua/token_bucket.lua`](../common/limiter/lua/token_bucket.lua)。

一个令牌一个桶，**所有模型合并计数**，Redis key 为 `rateLimit:v3:token:rpm:{token_id}`。
用 token_id 而不是原始密钥，避免密钥出现在 Redis key 和日志里。

| 来源 | 位置 | 热生效 |
|---|---|---|
|平台级|`options` 表 `TokenRequestRateLimitEnabled` / `TokenRequestRateLimitCount`|是，改完立即生效|
|令牌级|`tokens.rpm` 列|受 token 缓存 TTL 影响（`SYNC_FREQUENCY`，默认 60 秒）|

令牌级**替换**平台级。`tokens.rpm` 语义：

|值|含义|
|---|---|
|`0`|继承平台级配置（**数据库默认值**，所有已有令牌都是这个）|
|`-1`|该令牌不限流，忽略平台级|
|`> 0`|该令牌自己的上限|

Lua 脚本接口按 n 个桶设计，当前只传一个。要加用户桶、平台总量桶时调用方多传
`KEYS` 和参数即可，脚本不用改。多桶时必须由同一个脚本原子提交：先只读检查所有桶，
全部够才统一扣减——分多次调用会产生部分扣减，下层拒绝时上层额度已被白耗。

Redis 未启用（`REDIS_CONN_STRING` 为空）时放行并打警告日志。不做降级：多实例下各自计数会让额度按实例数放大。
